# IronWeb —— 个人创作博客网站

一个完全属于你自己的创作网站：**写小说 + 收藏视频**，支持电脑和手机访问，数据保存在你自己的电脑 / 服务器上。

> **✅ 本站已上线公网：https://iteq0511-ux.github.io/ironweb/ （GitHub Pages，免费、永不休眠）**
> 线上为"浏览器模式"（数据存在浏览器里，随时可用「导出 TXT」备份）；想启用带云端的完整版，见下方方案 A。

```
IronWeb/
├── server.js          # 后端服务（零依赖 Node.js，不需要 npm install）
├── package.json
├── start.bat          # Windows 一键启动（自动检测/安装 Node.js）
├── README.md
├── data/              # ★ 你的数据目录（自动生成）
│   ├── novels/        #   每本小说一个 JSON 文件
│   └── videos/        #   视频文件 + meta.json
└── public/            # 前端页面
    ├── index.html     # 首页（小说区 / 视频区）
    ├── novel.html     # 小说区（列表 / 回收站 / 导入导出 TXT）
    ├── editor.html    # 编辑器（章节 / 人物关系 / 设置 / 沉浸写作 / 阅读模式）
    ├── video.html     # 视频区（导入 / 导出 / 搜索 / 播放）
    ├── css/style.css
    └── js/            # common.js / api.js / particles.js / home.js / novel.js / editor.js / video.js
```

## 一、在电脑上本地运行（数据保存到本地 Web 目录）

1. 双击 **`start.bat`**（如果没有 Node.js 会自动安装，或到 nodejs.org 下载 LTS）。
2. 浏览器会自动打开 `http://localhost:3000`，开始使用。
3. 所有数据自动保存到本目录下的 **`data/`** 文件夹：
   - 小说 → `data/novels/`
   - 视频 → `data/videos/`
4. 想停止：关闭黑色命令行窗口即可。

> 首次打开会看到一本示例小说《星火》，方便体验全部功能，不需要时在小说区直接删除即可。

> 手机同一 Wi-Fi 下访问：电脑运行后，手机浏览器打开 `http://电脑IP:3000`（IP 可在命令行窗口看到或通过 ipconfig 查询）。这是局域网访问；要全球任何地方都能访问，看下面的部署。

## 二、免费部署到公网（任何地方都能打开，且完全免费）

网站做了双模式设计：**有后端 → 数据存服务器磁盘；纯静态托管 → 自动降级为浏览器存储**，所以下面两条路都可以，任选其一。

### 方案 A（完整版）：Render 免费云服务 —— 真后端，数据在云端，功能 100%

> 免费额度：每月 750 小时，官方说明无需信用卡。⚠️ 实测发现：**新注册的 Render 账号在创建第一个 Web 服务时，页面会反复弹出"Add Card"绑卡引导**（即使选择 Free 实例也弹），需要绑定一张信用卡验证后才能创建。有信用卡再走本方案；不想绑卡直接用上面的方案 B。

**步骤（约 10 分钟）：**

1. **注册 GitHub**：打开 https://github.com 注册一个免费账号（如果已有请忽略）。
2. **新建仓库**：点右上角 `+` → `New repository`，仓库名填 `ironweb`，选 **Public**，点 `Create repository`。
3. **上传代码**：进入仓库页面，点 `Add file` → `Upload files`，把本项目 `IronWeb` 文件夹里的**所有文件**（server.js、package.json、public 整个文件夹、README.md）拖进去上传（不要上传 data 空文件夹也行）。传完后点 `Commit changes`。
4. **注册 Render**：打开 https://render.com 注册，用 GitHub 账号一键登录。
5. **创建 Web 服务**：点 `New +` → `Web Service` → 连接你的 GitHub → 选择 `ironweb` 仓库。
6. **填写配置**：
   - Name：`ironweb`
   - Runtime：`Node`
   - Build Command：留空
   - Start Command：`node server.js`
   - Instance Type：选 **Free**
   - 点 `Create Web Service`
7. 等 2~5 分钟部署完成后，Render 会给你一个 **`https://ironweb-xxxx.onrender.com`** 的正式网址 —— 从此你在任何地方、任何设备（手机/电脑）打开这个网址就能用，数据保存在 Render 云端。
8. **（重要）随时备份**：在网站上把小说导出 TXT，或下载视频，数据就永远属于你。

> 云端版的数据存在 Render 服务器磁盘上（换设备也能看到同一份数据），和本地 `start.bat` 版是两个独立的数据副本；想保留本地副本，随时用「导出 TXT / 下载视频」即可。

### 方案 C（★ 数据存回你自己电脑）：本地服务 + 免费内网穿透

> 想要"任何地方打开网页、点保存就写进自己电脑"就用这个。**完全免费**（Cloudflare 快速隧道），缺点是**你电脑需要开机**且服务在运行。

1. 双击项目里的 **`启动公网.bat`**：
   - 自动启动本地服务（没运行时才启动）；
   - 自动建立免费公网隧道（cloudflared，已在 `tunnel\` 目录备好）；
   - 自动抓取并**显示公网网址**，同时复制到剪贴板、保存到 `我的公网网址.txt`、打开浏览器。
2. 把显示的公网网址（形如 `https://xxxx.trycloudflare.com`）发给任何人，或用手机打开——**这就是你的网站**，数据直接读写你电脑的 `data\` 目录。
3. 关机后网址失效；下次开机再双击 `启动公网.bat`，会得到**新的网址**（免费隧道随机分配，这是免费方案的唯一代价）。
4. 想长期固定网址：可注册 Cloudflare 账号并绑定自己的域名（免费托管 + 免费 Tunnel），或升级 cpolar 等国内穿透服务的固定域名套餐（付费）。



### 方案 B（最简单 · 本网站已用此方案上线）：GitHub Pages 免费静态托管 —— 不用服务器，永不休眠

> 没有后端，网页自动进入"浏览器模式"：小说/视频数据保存在**当前浏览器**里，换设备不互通，但**导出/导入 TXT 随时可备份**。适合"先免费上线再说"，且永不休眠、访问最快。

**实际部署步骤（已完成，记录如下，以后更新网站按此操作）：**

1. 代码已推送到 GitHub 仓库：`https://github.com/iteq0511-ux/ironweb`（仓库根有 index.html 自动跳转到 public/）。
2. 仓库页面 → `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 `main` → 文件夹 `/ (root)` → `Save`。
3. 等约 1 分钟，网站地址：**https://iteq0511-ux.github.io/ironweb/**（已实测可访问）。
4. 以后更新网站：**改好文件后，双击项目里的 `更新网站.bat`**（会自动提交并推送到 GitHub），约 1 分钟后线上自动更新。想手动执行也可以：在项目目录运行 `git add -A` → `git commit -m "说明"` → `git push origin main`。

> 提示：静态托管时视频会占用浏览器存储空间，建议视频尽量用"添加链接"方式收藏。

## 三、功能清单

| 区域 | 功能 |
|---|---|
| 首页 | 小说区 / 视频区双入口，显示当前数据统计与运行模式 |
| 小说区 | 小说列表与数量、**回收站**（恢复/彻底删除/清空）、**导入 TXT**（文件或粘贴，自动按"第X章"拆分）、**导出 TXT**（单本/全部） |
| 编辑器 | 左侧：**章节**（新建/重命名/上下移/删除）、**人物关系**（添加人物、创建关系、关系图谱）、**设置**（字号/行距/字体/字体颜色/编辑区主题） |

| 阅读模式 | 点「阅读」进入**黑底白字全屏阅读**，界面干净，底部「上一章 / 下一章 / 退出阅读」，支持 ← → 键翻章、Esc 退出 |
| 主题外观 | **全程亮色主题**（浅色背景 + 深色文字）+ **动态粒子背景**；仅阅读模式保持黑底白字；编辑器「设置 → 编辑区主题」可切回深色 |
| 视频区 | **导入视频**（本地文件上传）、**添加链接**、**搜索**、播放（支持进度条拖动）、**导出**（下载原文件）、删除 |

## 四、常见问题

- **端口被占用？** 改 `server.js` 顶部的 `PORT`，或设置环境变量 `PORT=3001`。
- **想改数据目录位置？** 设置环境变量 `IRONWEB_DATA` 指向新目录即可。
- **电脑休眠/关机时公网访问不了？** 这是正常的，本地服务需要电脑开机运行。要 24 小时在线请用方案 A（Render）。
- **数据安全**：定期在小说区「导出全部 TXT」、视频区导出视频做备份。
